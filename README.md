# LearningHarness

Source, releases, issues and contributions now live at **[learningharness/learningharness](https://github.com/learningharness/learningharness)**. LearningHarness is MIT licensed, maintained by [arvindm1991](https://github.com/arvindm1991).

This repository is retained as a read-only pointer to preserve existing links. Please open new issues and pull requests in the consolidated repository.

## Install

Start with the [canonical install guide](https://learningharness.dev/install.md). The [install manifest](https://learningharness.dev/install.json) lists the current host-specific packages and checksums. Existing installer URLs on learningharness.dev remain unchanged.

Preserved beta installers are also available in the [consolidated releases](https://github.com/learningharness/learningharness/releases). GitHub source-code archives are not plugin installers.

For requirements, restart and hook approval steps, see the [Codex guide](https://learningharness.dev/docs/codex/) or [Claude Code guide](https://learningharness.dev/docs/claude-code/).
